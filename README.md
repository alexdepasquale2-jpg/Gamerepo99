# WelCum HoMe

DON QUIXOTE WAS RIGHT.
THEY WANT YOU INSIDE.
THEY COME WHILE YOU SLEEP.

A slapstick death simulator on a sun-bleached La Mancha plain. The buildings grew wooden insect legs. They hunt you, fight over you, and the one that swallows you gets bigger. Dying in a new way writes a line in the Book of Ends.

The old Hearthfall simulation still lives under `src/sim` so its tests keep running. The game that boots is WelCum HoMe.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

- **Step outside** from the title.
- **WASD** or the arrow keys to walk. Hold the mouse to flee toward the cursor.
- **B** opens the Book of Ends.
- **Esc** pauses.

Outhouses, wells, market stalls, farmhouses, bakeries, taverns, the blacksmith, and the windmill are awake. The church, bullring, aqueduct, and castle are in the roster and the book, still dreaming.
